# Magic System Reference

**Status:** Working design specification  
**Version:** 0.2  
**Date:** July 25, 2026

## 1. Core cosmology

Three primordial forces define creation:

| Primordial force | Principle                                    | Role in creation                                       | Role in spellcraft                                                             |
| ---------------- | -------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------ |
| **Arcane**       | Possibility, chaos, creation, transformation | Makes existence and change possible                    | Supplies unstable potential that can become something reality was not          |
| **Mana**         | Order, structure, containment, persistence   | Gives possibility a stable form                        | Pulls ambient essence into a controlled structure and holds the spell together |
| **Void**         | Absence, emptiness, nonexistence             | Predates creation and returns formed things to nothing | Removes energy, structure, connection, or possibility                          |

The creation cycle can be summarized as:

> **Arcane makes existence possible. Mana gives it form. Void returns it to nothing.**

The three forces also produce the fundamental conditions of reality when joined:

| Combination              | Derived force       | Meaning                                                       |
| ------------------------ | ------------------- | ------------------------------------------------------------- |
| **Mana + Void**          | **Space**           | Emptiness given boundaries, dimension, position, and relation |
| **Arcane + Void**        | **Time**            | Change, sequence, impermanence, and entropy                   |
| **Mana + Arcane**        | **Creation / Form** | Possibility stabilized into persistent existence              |
| **Mana + Arcane + Void** | **Reality**         | Created form existing within Space and undergoing Time        |

Space is structured emptiness. Void supplies the absence, while Mana defines where that absence begins, ends, and relates to everything around it. Arcane may help Space magic violate ordinary geometry, but it is not a component of Space itself.

Time is the passage between new possibility and the loss of prior states:

> **Arcane creates what might become. Void consumes what no longer is. Time is the passage between them.**

Mana is still needed to contain and manipulate Time safely, but Mana is not part of Time. Stasis is therefore not Time magic; it is Mana resisting Time by enforcing persistence.

Creation is Void's direct counterforce. It does not recover something hidden inside the Void. It uses a surviving pattern—such as a True Name, soul-anchor, memory, preserved rune-pattern, temporal echo, or divine knowledge—to recreate what the Void erased. Total unmaking can only be reversed by the highest Creation magic or a creator deity with a sufficiently complete pattern.

### The basic casting formula

> **Mana + runic instructions + ambient essence = spell**

- **Mana** attracts, organizes, contains, and controls essence.
- **Essence** supplies the substance and natural behavior of an element.
- **Runes** tell the Mana what essence to gather and what structure to create.
- **Affinity** determines how easily a caster can sense, attract, and control a particular essence.

A Fire Bolt does not convert Mana into Fire. The caster builds a Mana lattice tuned to Fire, pulls Fire essence into that lattice, contains it, propels it, and releases it on impact.

### Exceptions

- **Direct Mana magic** uses the Mana structure itself as the spell. It is reliable and largely independent of local essence, but is less naturally destructive than most elemental magic.
- **Arcane magic** uses Mana to force raw possibility into one temporary, predictable outcome.
- **Void magic** does not gather Void essence. The caster uses Mana to define and contain an intentional absence inside the spell structure.
- **Divine power** originates with a deity. It is not produced by arranging ordinary elemental runes.

## 2. Magic classification

Every magical ability should be described using separate classification layers:

| Layer            | Question answered               | Examples                                   |
| ---------------- | ------------------------------- | ------------------------------------------ |
| **Source**       | What power does it use?         | Fire, Mana, Life, Light, Void              |
| **School**       | What does the magic accomplish? | Evocation, Restoration, Illusion           |
| **Form**         | How is it delivered or shaped?  | Touch, projectile, beam, cone, aura        |
| **Role**         | Why does the player use it?     | Damage, control, healing, support, stealth |
| **Divine state** | Is a deity influencing it?      | None, Holy, Corrupted                      |

This prevents terms such as “Melee,” “Ranged,” and “Support” from becoming schools. They are forms or tactical roles. It also allows an Elementalist to use one element in many ways instead of learning only larger projectiles.

### Magical hierarchy

| Layer                                    | Members                                                                            | Meaning                                                                                                     |
| ---------------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Primordial forces**                    | Arcane, Mana, Void                                                                 | The foundational conditions from which existence, spellcraft, and unmaking arise                            |
| **Primary essences**                     | Fire, Ice, Poison, Water, Lightning, Life, Death, Light, Shadow, Earth, Air, Sonic | Magically irreducible resonances from which the physical and magical world is formed                        |
| **Compound essences and derived forces** | Lava, Steam, Storm, Plague, Space, Time, Creation, Spirit, and others              | Stable results created by joining primary essences, primordial forces, or both through a specific structure |
| **Divine energy**                        | Holy, Corruption                                                                   | A deity's intact or defiled influence upon miracles and ordinary magic                                      |

A primary essence is **magically** irreducible, not scientifically indivisible. Ice, Lightning, and Sonic remain primary even though mundane scholars can describe them as states, charge, or vibration. The magical world recognizes each as a distinct fundamental resonance.

Examples:

| Ability          | Classification                                               |
| ---------------- | ------------------------------------------------------------ |
| **Fire Bolt**    | Fire + Evocation + Projectile + Ranged damage                |
| **Death Touch**  | Death + Affliction + Touch + Drain                           |
| **Obscure**      | Shadow + Illusion + Targeted zone + Control                  |
| **Flame Blade**  | Fire + Enhancement/Evocation + Weapon + Melee damage         |
| **Mend**         | Life + Restoration + Touch or short range + Healing          |
| **Sacred Flame** | Fire + Evocation + Divine/Holy seal + Damage or purification |

## 3. Learnable magical forces

### Primordial forces

| Force      | Meaning                                         | Primary uses                                                                                                                | Important limits                                                                    |
| ---------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Mana**   | Order, form, magical structure, and persistence | Force constructs, bolts, shields, binding, stabilization, dispelling, reinforcing other spells                              | Dependable but usually less specialized and less destructive                        |
| **Arcane** | Unbounded possibility and creative chaos        | Reality alteration, spatial distortion, probability, transformation, teleportation, unstable creation                       | Difficult to predict; requires Mana to force a specific result                      |
| **Void**   | Absence, severance, silence, and erasure        | Anti-magic, draining magical energy, breaking connections, silencing effects, destroying conjured matter, eventual unmaking | No ambient essence exists to gather; containment failure is exceptionally dangerous |

### Natural elements

| Element       | Meaning                                                           | Primary uses                                                                                            | Mechanical identity                                                    |
| ------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Fire**      | Heat, combustion, ignition, and consuming change                  | Direct damage, ignition, light, area denial, forging, cauterization                                     | Aggressive damage, burning, spreading, environmental interaction       |
| **Ice**       | Cold, crystallization, stillness, and preservation                | Slowing, freezing, barriers, preservation, brittle armor, terrain control                               | Movement control and gradual freeze buildup                            |
| **Poison**    | Toxins, venom, disease, and hostile chemistry                     | Damage over time, weakness, paralysis, sickness, alchemy, contamination                                 | Persistent effects and stacking afflictions                            |
| **Water**     | Flow, pressure, fluidity, and adaptation                          | Pushing, pulling, extinguishing, cleansing, cutting jets, shaping liquids                               | Positioning, force, redirection, and environmental utility             |
| **Lightning** | Electrical charge, conduction, and sudden release                 | Fast damage, interruption, chaining, stunning, powering devices                                         | Speed, burst damage, conduction, and brief disruption                  |
| **Light**     | Illumination, color, refraction, visibility, and focused radiance | Revealing, blinding, signaling, projection, mirages, invisibility through refraction, concentrated rays | Controls what becomes perceptible; neither moral nor inherently divine |
| **Shadow**    | Obscurity, concealment, diminished perception, and the unseen     | Stealth, muffling, accuracy reduction, false silhouettes, bindings, ambush                              | Attacks detection and perception; it is not inherently evil            |
| **Earth**     | Stone, soil, minerals, stability, and weight                      | Armor, barriers, projectiles, terrain shaping, mining, structural support                               | High impact, defense, physical persistence, and terrain control        |
| **Air**       | Motion, pressure, breath, and open space                          | Pushing, lifting, cutting wind, falling control, flight, ventilation                                    | Mobility and physical repositioning                                    |
| **Sonic**     | Vibration, resonance, rhythm, and sound                           | Disorientation, interruption, shattering, communication, echolocation                                   | Concentration disruption, resonance, and material weakness             |

### Vital forces

| Force     | Meaning                                                                | Primary uses                                                                     | Important limits                                                                                     |
| --------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Life**  | Vitality, growth, reproduction, adaptation, and biological persistence | Healing, regeneration, vigor, plant growth, adaptation, flesh shaping            | Not inherently good; misuse can cause tumors, parasitism, mutation, or uncontrolled growth           |
| **Death** | Cessation, decay, lost vitality, passage, and the boundary of life     | Withering, vitality drain, healing suppression, decay, spirits, peaceful passage | Not inherently evil; natural death and mercy belong here, while soul violation belongs to Corruption |

Life and Death are opposed, but neither is a moral alignment.

Light and Shadow are functional opposites without being moral alignments:

- **Light** makes something perceptible through illumination, transmission, revelation, color, and projection.
- **Shadow** prevents something from being perceived through concealment, absorption, muffling, and obscurity.
- **Darkness** is merely insufficient Light.
- **Shadow essence** actively interferes with perception.
- **Void** does not hide anything; it makes the thing absent.

## 4. Compound essences and derived forces

Compound essences are not lesser or artificial elements. They are stable magical resonances produced by a specific relationship among multiple sources. Different runic structures can create different compounds from the same components.

### Discovery and use

A caster first creates a compound using multiple cores joined through a **Converge** rune:

> **Fire + Earth + Converge = Lava**

After the formula has been stabilized and fully understood, the caster may discover a dedicated compound rune. That rune is an efficient shorthand for the established structure. The original multi-core formula remains available and is more flexible, while the shorthand is faster, cheaper, and easier to cast.

Compound affinities are derived from the caster's relationship to their components, modified by how harmonious, reactive, or opposed those components are. A dedicated compound tradition can eventually become a specialization of its own. A Metal Elementalist, for example, may begin as an Earth specialist who discovers and repeatedly stabilizes the Metal aspect.

### Known and proposed compounds

| Compound or aspect     | Components                                               | Meaning and primary uses                                                                          |
| ---------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Lava**               | Fire + Earth                                             | Molten stone, heat that persists physically, terrain destruction, forging                         |
| **Steam**              | Fire + Water                                             | Pressure, scalding vapor, concealment, engines, sudden expansion                                  |
| **Storm**              | Air + Water + Lightning                                  | Weather, wind-driven rain, chained conduction, broad environmental control                        |
| **Metal**              | Earth + Transmutation structure                          | Refined mineral, weapons, armor, machinery, magnetic or conductive behavior                       |
| **Crystal**            | Earth + Mana                                             | Ordered mineral growth, storage, resonance, spell focuses                                         |
| **Plant / Overgrowth** | Life + Earth + Water                                     | Roots, vines, crops, rapid ecosystems, living structures                                          |
| **Blood**              | Life + Water                                             | Circulation, vitality transport, lineage, biological tracking                                     |
| **Bone**               | Life + Earth, or Death applied to remains                | Structure, growth, remains, armor, necromantic construction                                       |
| **Acid**               | Poison + Water                                           | Corrosive liquid, material dissolution, persistent contamination                                  |
| **Plague**             | Poison + Death                                           | Contagious affliction, systemic collapse, spreading decay                                         |
| **Smoke**              | Fire + Air, often Shadow                                 | Obscuring particulates, choking, signaling, carrying heat or toxins                               |
| **Mud**                | Earth + Water                                            | Adhesion, slowing terrain, shaping wet earth, construction                                        |
| **Dust / Sand**        | Earth + Air                                              | Erosion, abrasion, blinding clouds, granular movement                                             |
| **Eclipse / Twilight** | Light + Shadow                                           | Contrast, silhouettes, partial revelation, false appearance, the boundary between seen and unseen |
| **Rot / Decay**        | Death + Poison, or Death + Time                          | Decomposition, material weakening, accelerated deterioration                                      |
| **Gravity**            | Space structured through Earth or reinforced Mana        | Weight, attraction, compression, altered trajectories                                             |
| **Dream**              | Spirit + Illusion, or Arcane + Illusion                  | Dream entry, symbolic perception, constructed inner worlds                                        |
| **Space**              | Mana + Void                                              | Distance, dimensions, portals, spatial locks, pocket spaces, severed adjacency                    |
| **Time**               | Arcane + Void                                            | Haste, slowing, aging, delay, temporal echoes, controlled entropy                                 |
| **Creation / Form**    | Mana + Arcane                                            | Stable manifestation, reconstruction, repair of Void erasure, new form                            |
| **Spirit**             | Mana + Arcane arranged as persistent identity and agency | Souls, memory, will, possession, astral travel, spiritual wards and communication                 |

Spirit is best understood as a specialized expression of Creation rather than a primary essence. Mana gives identity persistence and Arcane gives it agency, possibility, and change. Life binds a spirit to a living body, while Death governs the separation and passage that occurs when life ends.

### Space magic

Because Space is **Mana-structured Void**, its effects alter the defined emptiness between things:

- **Compress Distance:** reduces the structured separation between two locations.
- **Expand Distance:** inserts more structured emptiness between locations.
- **Portal:** connects the boundaries of two spatial structures.
- **Spatial Lock:** reinforces a location against teleportation or spatial severance.
- **Pocket Space:** encloses a bounded region of Void inside a Mana shell.
- **Sever Space:** breaks the spatial relationship between adjacent locations.

### Time magic

Time governs when and how quickly one state gives way to another:

- **Hasten:** accelerates change within a target.
- **Slow:** suppresses a target's progression through local Time.
- **Age:** advances biological or material deterioration.
- **Revert:** reconstructs a recent prior state from a surviving temporal echo.
- **Temporal Echo:** repeats or reveals the residue of a recent action.
- **Delay:** separates an action from the moment its effect occurs.
- **Time Sever:** uses Void to remove a brief interval from perception or action.
- **Stasis:** uses overwhelming Mana to resist Time; it is related but not itself a Time effect.

Time cannot freely retrieve a state that Void has completely consumed. Reversion requires a preserved echo or pattern, and restoring something truly erased requires Creation.

## 5. Divine energy

### Recommended terminology

| Term           | Definition                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| **Divine**     | The umbrella category for power originating from a deity                                               |
| **Holy**       | Divine power flowing through an intact bond and remaining true to the deity’s nature and purpose       |
| **Corruption** | Divine power that has been twisted, poisoned, stolen, violated, or turned against its intended purpose |

Holy does not mean gentle, radiant, or universally benevolent. The uncorrupted power of a war, death, storm, or shadow deity can be terrifying. It is Holy because it remains true to its divine source.

Corruption is distinct from Death, Shadow, Poison, and Void:

- Death can be natural and merciful.
- Shadow can protect and conceal.
- Poison is a natural or alchemical force.
- Void is absence without moral intent.
- Corruption is a violation of sacred purpose and is inherently defiling.

### Spells, miracles, and hybrid invocations

| Ability type              | Construction                           | Acquisition                                                                     | Typical cost                                                                     |
| ------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **Spell**                 | Mana lattice + runes + essence         | Study, practice, research, or observation                                       | Mana, essence availability, reagents                                             |
| **Miracle / Divine Gift** | Divine power + divine intent           | Granted through devotion, covenant, favor, a bargain, or being chosen           | Favor, devotion, conditions, cooldowns, or a deity-specific price                |
| **Consecrated spell**     | Normal spell + a deity’s Holy seal     | Requires both spell knowledge and divine authorization                          | Mana plus favor or a divine condition                                            |
| **Corrupted spell**       | Normal spell infiltrated by Corruption | Defilement, a corrupt bargain, stolen power, infection, or deliberate violation | Mana plus taint, instability, sacrifice, dependency, or another corruptive price |

There is no ordinary **Holy element rune**. A deity may grant a unique **Divine Seal** that attaches outside the normal spell circuit. Copying the visible symbol without the divine bond produces no Holy power.

Corruption may appear as a broken, inverted, overwritten, or parasitic seal. It can enter the Mana lattice through damaged connections and alter the spell from within.

### How Holy energy influences a Mana spell

Holy power does not replace the spell’s element. It adds divine purpose and authority to an existing structure.

Depending on the deity and domain, a Holy influence may:

- reinforce or stabilize the Mana lattice;
- purify Corruption or hostile afflictions;
- allow the spell to affect souls, oaths, curses, or otherwise unreachable targets;
- make the spell discriminate according to a divine rule;
- extend the spell beyond normal biological or physical limits;
- convert an ordinary effect into judgment, protection, revelation, mercy, or another divine expression.

Examples:

- A Fire spell consecrated by a forge deity may strengthen metal without burning its wielder.
- A Fire spell consecrated by a sun deity may expose hidden creatures and burn Corruption.
- A Death spell consecrated by a deity of passage may release a trapped spirit.
- A Shadow spell consecrated by a protective deity may hide refugees from hostile detection.
- A Life spell enhanced by Holy power may restore a soul or heal a wound that biological regeneration cannot repair.

The deity’s nature matters more than the element. A Holy spell cannot be freely configured in ways that violate the granting deity.

### How Corruption influences a Mana spell

Corruption uses the Mana lattice as a structure to infest. It commonly offers immediate power or convenience while introducing long-term harm.

It may:

- reduce the immediate Mana cost by substituting a corruptive price;
- increase force, duration, spread, or penetration;
- ignore ordinary ethical, biological, or spiritual limits;
- twist targeting, making a spell predatory or indiscriminate;
- create dependency, cravings, permanent taint, or escalating sacrifice;
- destabilize future spells or spread into the caster, target, equipment, and environment;
- distort an element’s purpose rather than merely changing its damage color.

Examples:

| Base source   | Holy influence                                                    | Corrupted influence                                                               |
| ------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **Mana**      | Protective seals, truthful oaths, stable wards                    | Compulsive bindings, domination, inescapable contracts                            |
| **Arcane**    | Inspired creation or a deity-authorized transformation            | Uncontrolled mutation, impossible geometry, reality wounds                        |
| **Void**      | Sacred silence, banishment, severing Corruption                   | Hunger, identity erosion, indiscriminate unmaking                                 |
| **Fire**      | Purification, courage, sacred forging, judgment                   | Agony, soul-scarring flame, fire that feeds on suffering                          |
| **Ice**       | Preservation, patience, protection from decay                     | Imprisonment, emotional numbness, flesh preserved in torment                      |
| **Poison**    | Natural balance, medicinal venom, punishment with a defined limit | Virulence, addiction, contagious spite, resistant plague                          |
| **Water**     | Cleansing, renewal, safe passage                                  | Pollution, drowning, leeching, water that carries taint                           |
| **Lightning** | Revelation, swiftness, decisive judgment                          | Torture, involuntary motion, nerves burned for power                              |
| **Life**      | Restoration, fertility, sacred growth, miraculous healing         | Malignant growth, parasitism, forced mutation, flesh that refuses to die          |
| **Death**     | Peaceful passage, release, final rest, severing undeath           | Soul bondage, consumption, denial of rest, spiritual mutilation                   |
| **Light**     | Revelation, guidance, truthful sight, consecrated radiance        | False revelation, painful overexposure, obsession, light that burns away identity |
| **Shadow**    | Sanctuary, secrecy, protection of the vulnerable                  | Paranoia, isolation, predation, concealment that consumes identity                |
| **Earth**     | Sanctuary, endurance, sacred ground, honest craft                 | Petrifying captivity, blighted soil, structures that imprison inhabitants         |
| **Air**       | Freedom, breath, travel, cleansing wind                           | Suffocation, invasive whispers, stolen breath                                     |
| **Sonic**     | Hymns, truth, harmony, communication                              | Compulsion, maddening resonance, voices that overwrite thought                    |

### Holy and Corruption in the same effect

Holy and Corruption are opposing states of divine power, not a stable dual-element combination.

- Holy power attempts to purge or restore the corrupted divine pattern.
- Corruption attempts to defile, consume, or overwrite the Holy pattern.
- If both are forced into the same Mana lattice, they contest control of it.
- A failed contest can collapse the spell, injure the caster, damage the divine bond, or spread Corruption.
- A corrupted Holy gift is normally a converted or infected gift, not a clean mixture of two damage types.

Rare paradoxical abilities may deliberately hold both states in tension, but they should be exceptional, unstable, and narratively significant.

## 6. Schools of magic

A school describes the theory and purpose of a spell, not its element or range. A spell may belong to more than one school.

| School            | Definition                                                                     | Typical effects                                                                   |
| ----------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| **Evocation**     | Directly manifests and releases magical or elemental force                     | Bolts, beams, explosions, walls, blades, impact, raw damage                       |
| **Restoration**   | Restores a creature or system toward a healthier or functional state           | Healing, cleansing, stamina recovery, repairing living tissue, recovery           |
| **Warding**       | Prevents, resists, redirects, seals, or dismantles hostile magic               | Barriers, resistance, reflection, containment, dispelling, magical locks          |
| **Enhancement**   | Temporarily improves an existing creature, item, sense, movement, or attribute | Weapon infusions, haste, strength, heightened senses, temporary resistance        |
| **Enchantment**   | Binds persistent magic into an item, structure, trap, building, or location    | Magic weapons, permanent wards, runic machines, traps, enchanted tools            |
| **Illusion**      | Alters perception without necessarily changing the underlying object           | Concealment, false sights and sounds, decoys, muffling, sensory distortion        |
| **Transmutation** | Changes matter, bodies, properties, or elemental states                        | Shapechanging, material conversion, flesh shaping, hardening, liquefying          |
| **Conjuration**   | Summons, creates, transports, or spatially relocates creatures and objects     | Summoning, portals, teleportation, temporary constructs, extradimensional storage |
| **Divination**    | Discovers information beyond ordinary senses                                   | Detection, identification, tracking, remote viewing, prediction, revealing        |
| **Affliction**    | Places persistent harmful conditions on a target                               | Curses, disease, poison, weakness, healing suppression, decay, ongoing damage     |

### Related terms that are not schools

- **Elementalism** is specialization in an element.
- **Necromancy** is a cross-school practice using Death. It may include Affliction, Conjuration of spirits, Transmutation of remains, or Enchantment of a corpse.
- **Healing** is primarily a function of Restoration, often using Life, Water, or Mana.
- **Melee** and **Ranged** are delivery forms.
- **Support**, **Damage**, **Control**, **Stealth**, and **Utility** are tactical roles.
- **Summoning** and **Teleportation** are practices within Conjuration.

## 7. Rune grammar

A rune formula is a magical sentence. The element supplies the subject matter, while the surrounding runes state how Mana should gather, shape, deliver, and resolve it.

### Rune families

| Rune family    | Purpose                                         | Examples                                                         |
| -------------- | ----------------------------------------------- | ---------------------------------------------------------------- |
| **Core**       | Selects the essence or primordial force         | Fire, Life, Mana, dual Fire/Air, contained Void absence          |
| **Anchor**     | Defines where the spell begins or what holds it | Caster, weapon, object, ground, existing flame                   |
| **Target**     | Defines what the spell may affect               | Self, creature, object, point, marked target, area               |
| **Delivery**   | Defines how the spell reaches its target        | Touch, projectile, beam, spray, tether, aura, field              |
| **Geometry**   | Defines the spell’s physical shape              | Point, line, cone, sphere, ring, wall, blade                     |
| **Path**       | Defines how a moving spell travels              | Straight, arc, wave, seeking, chain, orbit, return               |
| **Effect**     | Defines what happens when the spell resolves    | Impact, burst, restore, bind, drain, obscure                     |
| **Duration**   | Defines how long the structure remains          | Instant, sustained, persistent, delayed                          |
| **Trigger**    | Defines when a prepared spell activates         | Contact, impact, proximity, damage taken, command, expiry        |
| **Constraint** | Limits or protects part of the formula          | Contain, exclude caster, maximum targets, boundary, safe release |

The previously described example is:

> **Fire core + ranged projectile + wave path + burst**

This produces a Fire projectile that follows a curved or oscillating path and then explodes. Adding **Seek** would make it home toward a target rather than merely travel nonlinearly.

### Anchor runes

| Rune                | Definition                                                 | Common use                                                             |
| ------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Caster**          | Begins and remains centered on the caster                  | Self buffs, auras, shields                                             |
| **Weapon**          | Binds the spell to a held or designated weapon             | Elemental blades, empowered strikes                                    |
| **Object**          | Anchors the spell to a non-weapon item                     | Enchantment, traps, tools                                              |
| **Ground**          | Anchors the spell to terrain or a fixed point              | Walls, zones, runic circles                                            |
| **Existing Source** | Requires a matching material or phenomenon already present | Manipulating an existing fire, body of water, shadow, corpse, or sound |
| **Remote Mark**     | Anchors to a previously marked creature or location        | Tracking, delayed curses, remote activation                            |

### Target runes

| Rune         | Definition                                               | Common use                       |
| ------------ | -------------------------------------------------------- | -------------------------------- |
| **Self**     | The caster is the only valid target                      | Shroud, personal ward            |
| **Creature** | A living, undead, spiritual, or otherwise animate target | Bolts, healing, afflictions      |
| **Object**   | A discrete physical item or structure                    | Enchantment, breaking, repair    |
| **Point**    | A selected location in space or terrain                  | Teleportation, explosions, zones |
| **Marked**   | A target carrying a compatible magical mark              | Seeking spells, linked effects   |
| **Area**     | All valid targets inside a defined geometry              | Fields, storms, group effects    |

### Delivery runes

| Rune           | Definition                                                          | Common use                          |
| -------------- | ------------------------------------------------------------------- | ----------------------------------- |
| **Touch**      | Transfers the spell through direct contact                          | Death Touch, Mend, weapon imbuement |
| **Projectile** | Creates a contained moving packet                                   | Darts, bolts, fireballs             |
| **Beam**       | Maintains a direct line of continuous or instantaneous energy       | Rays, cutting jets, channels        |
| **Spray**      | Releases many droplets, particles, or fragments across a short area | Poison Spray, frost breath          |
| **Tether**     | Maintains a connection between caster and target                    | Draining, pulling, channeling       |
| **Aura**       | Radiates from and moves with an anchor                              | Shroud, warmth, silence             |
| **Field**      | Occupies a fixed region                                             | Obscure, wards, storms              |

### Geometry runes

| Rune             | Definition                                    | Common use                       |
| ---------------- | --------------------------------------------- | -------------------------------- |
| **Point**        | Concentrates the effect at one location       | Precise strikes, marks           |
| **Line**         | Extends along a narrow path                   | Beams, walls in formation        |
| **Cone**         | Widens outward from its origin                | Sprays, breath effects           |
| **Sphere**       | Fills or surrounds a three-dimensional area   | Bursts, bubbles, globes          |
| **Ring**         | Forms a circular boundary with an open center | Wards, exclusion zones           |
| **Wall**         | Creates a broad standing plane                | Barriers, terrain denial         |
| **Blade / Edge** | Forms a narrow cutting plane                  | Elemental weapons, cutting waves |

### Path runes

| Rune         | Definition                                                | Common use                             |
| ------------ | --------------------------------------------------------- | -------------------------------------- |
| **Straight** | Travels directly along its initial vector                 | Fast, efficient projectiles            |
| **Arc**      | Follows a predictable curved trajectory                   | Lobbed spells and obstacles            |
| **Wave**     | Oscillates or travels along a non-straight repeating path | Wandering projectiles, broad coverage  |
| **Seek**     | Corrects course toward a designated target                | Homing spells                          |
| **Chain**    | Jumps through multiple valid targets                      | Lightning, contagious magic            |
| **Orbit**    | Circles an anchor until released or expired               | Defensive motes, prepared attacks      |
| **Return**   | Attempts to travel back to its origin or anchor           | Reusable projectiles, returning blades |

## 8. Effect runes

Effect runes state what the spell does when its structure resolves. They can be combined, but every added effect increases complexity, Mana cost, instability, or research difficulty.

| Effect rune          | Definition                                                                                | Primary uses / schools                                             |
| -------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **Manifest**         | Brings a small quantity of the selected force into stable existence                       | Basic charms, Evocation, Conjuration                               |
| **Impact**           | Releases contained force into the target on contact                                       | Bolts, blunt force, Evocation                                      |
| **Burst**            | Releases the spell radially from a point                                                  | Explosions, area effects, Evocation                                |
| **Pierce**           | Narrows the effect to penetrate resistance or continue through a target                   | Beams, armor penetration, Evocation                                |
| **Edge**             | Compresses the spell into a cutting plane                                                 | Elemental blades, Wind Blade, Enhancement/Evocation                |
| **Push**             | Applies force away from the spell’s origin                                                | Air, Water, control, Evocation                                     |
| **Pull**             | Draws a target toward an anchor or point                                                  | Water, Shadow, tethers, Evocation/Conjuration                      |
| **Bind**             | Restricts movement, action, transformation, or magical behavior                           | Restraints, seals, Warding/Affliction                              |

## 11. Spell research and discovery

### Research loop

1. Learn individual runes or fragments from teachers, books, ruins, creatures, observation, experimentation, divine revelation, or recovered enchantments.
2. Arrange known fragments on a research canvas.
3. Draw connections between their nodes.
4. Commit Mana, time, reagents, and any required stored essence to a test.
5. Receive feedback about incomplete paths, unstable structures, incompatible effects, poor containment, or excessive complexity.
6. Revise and stabilize the formula through further study.
7. Record the completed spell in a grimoire.
8. Cast the recorded spell normally without redrawing it every time.

Manual drawing is primarily a research activity. Advanced casters may eventually improvise a formula during combat, but improvisation should be slower and carry substantial miscast risk.

The interface should evaluate connected nodes and rune relationships rather than precise handwriting. Lines may visually follow the player’s hand and then snap to nearby nodes.

### Useful failure states

| Failure          | Cause                                    | Result                                                              |
| ---------------- | ---------------------------------------- | ------------------------------------------------------------------- |
| **Fizzle**       | Incomplete circuit or insufficient Mana  | Spell fails with little effect                                      |
| **Essence leak** | Weak containment                         | Environmental hazard or damage around the formula                   |
| **Backfire**     | Invalid anchor, target, or delivery path | Spell affects the caster or origin                                  |
| **Overload**     | Too much essence for the Mana lattice    | Explosion, status effect, damaged focus                             |
| **Reaction**     | Incompatible or reactive dual cores      | Unexpected combined effect                                          |
| **Drift**        | Arcane structure is too loose            | Spell resolves as a nearby possible outcome                         |
| **Erosion**      | Void containment fails                   | Runes, enchantments, Mana, or matter begin disappearing             |
| **Taint**        | Corruption enters an unstable circuit    | Spell succeeds in a twisted form and leaves persistent consequences |

### Discovery principles

- Simple charms teach individual magical “words.”
- Tier 1 spells teach complete magical sentences.
- New spells should usually be discoverable by recombining known runes.
- Named spells are stabilized formulas, not the only possible arrangements.
- Schools determine what theories a researcher understands; affinity determines what essence they can control.
- Divine Seals cannot be reverse-engineered into genuine Holy power without authorization from their source.

## 12. Affinity and specialization

Elemental affinity modifies:

- Mana cost;
- spell strength or effectiveness;
- essence sensing and gathering;
- learning speed;
- stabilization difficulty;
- miscast risk.

An Elementalist specializes in a source, not in a school. A Fire Elementalist may practice Evocation, Warding, Enhancement, Enchantment, Illusion through heat mirages, Transmutation, or Conjuration while remaining a Fire specialist.

Void is the exception to ordinary elemental specialization. Increased Void tolerance and power are acquired through Mana Erosion and metaphysical adaptation, not through a safe affinity track that can be retrained like Fire or Water.

### Provisional balance values

| Relationship             |  Power | Mana cost | Research rate |
| ------------------------ | -----: | --------: | ------------: |
| **Specialized element**  |   +25% |      −20% |          +30% |
| **Harmonious element**   |    +5% |       −5% |          +10% |
| **Neutral element**      | Normal |    Normal |        Normal |
| **Opposed element**      |   −15% |      +35% |          −30% |
| **Antithetical element** |   −25% |      +60% |          −45% |

These are starting values for testing, not final balance.

Specialization should be consequential but not permanently irreversible. Persistent study of an opposed force can gradually repair that affinity while weakening the caster’s original specialization.

### Important relationships

- Fire conflicts with Water and Ice, and harmonizes with Air.
- Air harmonizes with Fire, Lightning, and Sonic.
- Earth conflicts with Air and grounds Lightning.
- Water and Lightning are **reactive**: powerful together, but dangerous rather than naturally harmonious.
- Poison combines readily with Death and can be carried by Water.
- Life and Death are opposed but can coexist in cycles, ecosystems, and advanced formulas.
- Light and Shadow are opposed in perception, although combining them can produce Eclipse or Twilight effects.
- Arcane and Mana are cosmological complements in tension: possibility requires structure to become reliable.
- Void opposes both formed structure and unrealized possibility.
- Mana is broadly compatible with every learnable source because it structures spellcasting itself.
- Holy and Corruption are not part of the elemental affinity graph. They are governed by divine relationship, favor, and taint.

Avoid forcing every source into one perfect opposite pair. Use a relationship graph supporting harmony, opposition, reaction, grounding, amplification, and conversion.

## 14. Void practice and transformation

Void is not another destructive element. Fire burns, Death ends life or drains vitality, and Corruption violates divine purpose. Void removes form, substance, energy, connection, and ultimately possibility from existence.

> **Every use of Void consumes part of the structure used to contain it.**

Ordinary Void casters force absence into Mana matrices because Mana is the only force capable of giving that absence a safe boundary. The contradiction is inherently corrosive: Mana preserves structure while Void abolishes it.

Void is also completely neutral. It does not hate creation, delight in suffering, or distinguish between the innocent and guilty. At its purest, it recognizes all structure as a temporary violation of the emptiness that came before creation.

### Canonical evolution

> **Void-Touched → Voidbound → Hollow → First Consumption → Void Baptism → Voidborn**

| Stage            | Internal state                                                                                                | Resources                                  | Agency and path state                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------- |
| **Void-Touched** | The caster forces Void into Mana matrices; each casting erodes that matrix                                    | Health + shrinking Mana + growing Void     | Retains ordinary identity and class options while enough Mana remains |
| **Voidbound**    | The Mana matrix has been entirely consumed and replaced by a stable Void reservoir                            | Health + Void                              | All non-Void evolutions close unless Creation restoration intervenes  |
| **Hollow**       | The Void consumes identity and begins using the mortal body as its remaining structure and fuel               | Health + Void, then Health as casting fuel | Initially uncontrolled and relentlessly destructive                   |
| **Voidborn**     | Mortal structure has been completely consumed; form, health, and power are sustained as one contained absence | One unified Void pool                      | Becomes the embodiment of neutral destruction                         |

### Void-Touched: Mana erosion and the growing Void Pool

A Void-Touched caster still knows how to create an ordinary Mana lattice. Their Void spells place a deliberate absence inside that lattice. Every use damages the lattice and permanently converts part of its capacity:

> **Maximum Mana erased = maximum Void capacity created**

Initially, the conversion should be one-to-one for clarity. Balance testing may later introduce some loss during conversion.

- Maximum Mana gradually decreases as Void spells are used.
- Maximum Void rises by the converted amount.
- Current Mana regenerates at the normal rate, but only within the shrinking Mana maximum.
- Mana regeneration cannot restore maximum capacity already erased.
- Current Void regenerates using the character's former Mana-regeneration rate unless a stage-specific rule overrides it.
- Ordinary spells become progressively more costly and unstable because less internal Mana structure remains.
- Only Creation can reverse the permanent conversion.

Void-Touched spellcasting naturally passes through three phases:

1. **Initial exposure:** The caster has little or no Void capacity, so Void spells rely heavily on Mana and cause substantial erosion.
2. **Growing connection:** Void spells primarily spend Void Energy, but constructing and containing them continues to convert maximum Mana.
3. **Late conversion:** Most magical capacity belongs to Void. Conventional spellcasting becomes weak, inefficient, or impossible.

This is the central temptation:

> **Using Void makes Void magic stronger and easier while making every other magical path weaker and pushing the caster toward irreversible transformation.**

### Void-Touched resource UI

The UI should tell the transformation story before any class screen explains it:

- The Mana Pool begins as a completely blue bar.
- A separate Void Pool appears once the caster becomes Void-Touched.
- The Void bar is pitch black with a gray empty background. The gray is only exposed after Void points are spent.
- As maximum Mana is erased, the blue bar's maximum width shrinks.
- The maximum width of the black Void bar grows by the same amount.
- Mana expenditure empties only the surviving blue capacity; regeneration refills that capacity but never reclaims converted space.
- The bars should be aligned or visually opposed so black appears to devour blue over the course of the character's progression.

For example:

| Resource | Current | Maximum |
| -------- | ------: | ------: |
| Mana     |      32 |      55 |
| Void     |      27 |      45 |

The two maximums still represent the character's original magical capacity. What changes is which force owns that structure.

### Forced Voidbound evolution

When maximum Mana is completely consumed and the character meets the evolution level, the final fragment of the Mana matrix collapses and the evolution into **Voidbound** becomes mandatory:

- Void capacity occupies the full former magical pool.
- Mana regeneration becomes Void regeneration.
- Void-Touched spells evolve into their Voidbound forms.
- All internally cast Mana-and-essence spells become unusable.
- Every ordinary class evolution closes.
- Health remains intact because the character's physical structure has not yet been consumed.

To avoid trapping an underleveled character without usable resources, maximum Mana may stop at one point while additional erosion accumulates as **Pending Conversion**. Reaching the required level consumes that final point, applies the pending conversion, and forces the evolution.

### Creation restoration and sealing

A sufficiently powerful Creation mage can interrupt the path:

> **Mana + Arcane recreates the erased Mana matrix; a Creation seal prevents Void from entering it again.**

Successful restoration:

- removes the Void Pool;
- reconstructs maximum Mana from the person's surviving magical, spiritual, or True Name pattern;
- seals the connection to Void;
- removes all Void-Touched and Voidbound spells;
- reopens ordinary evolution paths;
- prevents the restored character from relearning Void magic unless the seal is deliberately broken.

Restoring a Void-Touched character is difficult. Restoring a Voidbound is far harder because the entire Mana matrix must be recreated. Once Hollowing begins to consume the body, ordinary high-level Creation may be insufficient. Reconstructing a Voidborn as their former mortal self should require legendary Creation power, a near-complete identity pattern, or direct intervention by a creator deity.

The cure is therefore a true escape from the Void route, not a way to keep its abilities without paying its cost.

### Voidbound spellcasting

A Voidbound has no internal Mana matrix and cannot structure ambient essence unaided. They may use conventional magic only through an external structure such as:

- a Mana focus;
- a Mana-infused artifact;
- a cooperating mage;
- a Creation lattice built into their body;
- a prepared enchantment that performs the structuring for them.

These methods should be less efficient and less flexible than ordinary spellcasting. Voidbound power instead centers on nullification, severance, erasure, consuming structured energy, and bringing progressively larger absences to bear.

### Becoming Hollow

Hollow is a dangerous transitional state, not a stable class. It begins when the Voidbound's connection and capacity exceed what their remaining mortal identity can control.

The Hollow loses its sense of self and attacks the nearest concentrations of structure:

- creatures;
- spells and magical constructs;
- enchantments;
- buildings;
- terrain;
- eventually its own carried equipment.

It is not enraged or bloodthirsty. Void encounters existence and destroys it.

While Hollow:

- Void regeneration is reduced to a tiny fraction of its previous rate.
- The body is not failing to regenerate; it is consuming nearly all regenerated Void to **baptize and remake itself in absence**.
- The Hollow uses its strongest available Void abilities relentlessly.
- When the Void Pool reaches zero, further ability costs are paid from Health.

### First Consumption and Void Baptism

The first point of Health spent on a Void ability triggers **First Consumption** and begins **Void Baptism**:

- The transition becomes irreversible without extraordinary Creation intervention.
- Health continues to erode even if the Hollow stops casting.
- Every additional Void ability consumes Health and hastens the transformation.
- Armor, resistance, Life magic, and ordinary healing cannot stop the loss.
- The body is not being wounded; the structure healing would act upon is being erased.

Control should return to the player shortly after First Consumption. The character regains enough identity to understand what is happening and sees their Health steadily disappearing. This creates a doomed final interval in which the player can decide what to do with the last moments of their mortal body, even though they can no longer save it by ordinary means.

### Dark-phoenix rebirth

When Health reaches zero:

- the normal death event is intercepted;
- the final mortal structure is consumed;
- the red Health bar and black Void bar collapse into one another;
- both bars reform as a single, larger Void Energy bar;
- the character emerges as **Voidborn** in an eruption or implosion of absence.

The unified maximum should preserve both physical and magical investment:

> **Voidborn Capacity = converted maximum Health + former maximum Void**

Constitution matters because it determines how much mortal structure was available for conversion. Magical investment matters because it determines how much Void the character had already learned to sustain.

The one-time rebirth should restore a substantial portion—potentially all—of the unified pool. The transformation only occurs once, so the dark-phoenix combat reversal can be extraordinarily powerful without becoming a repeatable survival mechanic.

### The Voidborn unified pool

A Voidborn no longer has separate health and power:

> **Its power is its body, and using its body is using its power.**

The unified Void Pool governs:

- physical integrity and continued manifestation;
- Void ability costs;
- damage received;
- resistance to erasure, spatial severance, and magical nullification.

This creates a distinct combat economy:

- powerful casting brings the Voidborn closer to its own unmaking;
- taking damage directly reduces its ability to retaliate;
- a basic attack must remain free so low energy never makes the character completely helpless;
- expelled Void can be reclaimed after some attacks;
- structured magic and enchantments can be consumed for power;
- Life magic and conventional healing have nothing to repair;
- Creation can reconstruct lost capacity if it possesses a usable pattern;
- reaching zero Void means the Voidborn is genuinely unmade.

Possible recovery abilities include:

| Ability                  | Function                                                                       |
| ------------------------ | ------------------------------------------------------------------------------ |
| **Recall**               | Pulls back Void left behind by recent abilities                                |
| **Nullify**              | Consumes an incoming spell and absorbs part of its ordered structure           |
| **Devour Enchantment**   | Destroys an enchanted effect or item charge for energy                         |
| **Consume Mana**         | Drains ordered magical energy and collapses it into usable Void                |
| **Rest in Absence**      | Recovers in a Void fracture, null zone, or place cut off from ordinary reality |
| **Creation Restoration** | Reconstructs lost manifestation using Mana, Arcane, and a preserved pattern    |

Recall should be the primary recovery rhythm: expend part of oneself, survive long enough to draw the expelled absence back in, and attack again.

### Voidborn nature and purpose

A completed Voidborn is the embodiment of destruction, not merely a person with Void abilities. Its former identity has been erased or subordinated to the principle it now embodies.

It is purely neutral:

- it does not destroy out of hatred, cruelty, vengeance, hunger, or Corruption;
- it does not recognize life, civilization, divinity, or beauty as reasons for preservation;
- it understands creation as temporary structure imposed upon the original emptiness;
- its only fundamental concern is returning all creation to the Void.

This makes Voidborn a terminal metaphysical path with severe narrative consequences. Factions, relationships, quests, and class goals based on ordinary mortal desires should fall away or become obstacles to unmaking. Any remnant of the original person that resists this purpose must be sustained by an exceptional surviving anchor, and that resistance should be a central conflict rather than the normal state.

Voidborn therefore remain distinct from every other dark-looking force:

| Force          | Final action                                        |
| -------------- | --------------------------------------------------- |
| **Death**      | Ends life and governs passage or decay              |
| **Shadow**     | Conceals what exists                                |
| **Corruption** | Defiles divine nature and purpose                   |
| **Void**       | Abolishes existence and returns creation to nothing |

- Void appears to remove light, color, particles, and sometimes part of the background itself.

## 16. Implementation model

A spell definition should store these concepts separately:

| Field              | Example for Fire Bolt                    |
| ------------------ | ---------------------------------------- |
| `sources`          | `Fire`                                   |
| `primarySchool`    | `Evocation`                              |
| `secondarySchools` | none                                     |
| `anchor`           | `Caster`                                 |
| `targets`          | `Creature`, `Object`, `Point`            |
| `delivery`         | `Projectile`                             |
| `geometry`         | `Point`                                  |
| `path`             | `Straight`                               |
| `effects`          | `Impact`, `Afflict: Burning`             |
| `duration`         | `Instant` with persistent Burning effect |
| `trigger`          | `Impact`                                 |
| `constraints`      | `Contain`, `Safe Release`                |
| `divineState`      | `None`                                   |
| `divineSource`     | null                                     |
| `tier`             | `Common / Tier 1`                        |

Recommended high-level enums or registries:

- `MagicSource`: Mana, Arcane, Void, Fire, Ice, Poison, Water, Lightning, Life, Death, Light, Shadow, Earth, Air, Sonic
- `MagicSchool`: Evocation, Restoration, Warding, Enhancement, Enchantment, Illusion, Transmutation, Conjuration, Divination, Affliction
- `DivineState`: None, Holy, Corrupted
- `SpellTier`: Charm, Common, and later tiers
- rune registries for Anchor, Target, Delivery, Geometry, Path, Effect, Duration, Trigger, and Constraint

Divine should not be inserted into `MagicSource`. A deity, covenant, granted seal, favor cost, and Divine state should be attached through separate fields.

### Compound definitions

Compound essences should be data rather than hard-coded exceptions:

| Field                   | Purpose                                                                           |
| ----------------------- | --------------------------------------------------------------------------------- |
| `compoundId`            | Stable identity such as `Space`, `Lava`, or `Plague`                              |
| `components`            | Required primary essences or primordial forces                                    |
| `relationship`          | Blend, reaction, alternation, containment, opposition, or another structural rule |
| `requiredRunes`         | Minimum grammar needed to produce the compound manually                           |
| `shorthandRuneUnlock`   | Research threshold for the dedicated compound core                                |
| `affinityRule`          | How component affinities and compound specialization combine                      |
| `environmentalBehavior` | What concentrations, reactions, or persistent matter it creates                   |

The same components may produce different results when arranged differently. A compound definition therefore needs both ingredients and relationship structure.

### Void progression state

Void transformation should be modeled independently from an ordinary class level:

| Field                         | Purpose                                                                    |
| ----------------------------- | -------------------------------------------------------------------------- |
| `voidStage`                   | None, VoidTouched, Voidbound, Hollow, Voidborn                             |
| `currentMana` / `maximumMana` | Surviving ordered magical capacity                                         |
| `manaErosion`                 | Permanent Mana capacity converted by Void practice                         |
| `pendingVoidConversion`       | Erosion held until the minimum Voidbound level is reached                  |
| `currentVoid` / `maximumVoid` | Current and converted Void capacity                                        |
| `voidRegeneration`            | Normally inherited from Mana regeneration; heavily suppressed while Hollow |
| `firstConsumptionTriggered`   | Marks the irreversible start of Void Baptism                               |
| `voidBaptismRate`             | Passive Health erosion after First Consumption                             |
| `unifiedVoidCapacity`         | Voidborn manifestation, health, and power in one value                     |
| `creationSealState`           | Whether the Void connection is open, being restored, or permanently sealed |

Evolution requirements should check both character level and metaphysical state. Reaching zero maximum Mana does not offer Voidbound as one menu choice; it forces the route and closes incompatible paths.
